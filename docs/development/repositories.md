# リポジトリ

Charalarm はこのリポジトリ ([takoikatakotako/charalarm](https://github.com/takoikatakotako/charalarm)) にまとめています (モノレポ)。
iOS・バックエンド・インフラ・管理画面・LP・ドキュメントがすべて入っています。

## 関係するリポジトリ

- **gcp-iac** — Google Cloud 側の設定 (Vertex AI を使うための Workload Identity Federation、予算アラートなど)

## アーカイブ済み

以前は分かれていたリポジトリです。今は使っていません。

- [charalarm-docs-old](https://github.com/takoikatakotako/charalarm-docs-old) (ドキュメント)
- [charalarm-backend-old](https://github.com/takoikatakotako/charalarm-backend-old) (バックエンド・インフラ)
- [charalarm-lp-old](https://github.com/takoikatakotako/charalarm-lp-old) (LP)
