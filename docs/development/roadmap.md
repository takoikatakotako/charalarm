# ロードマップ

Charalarm の今と、これからやること。細かい作業は GitHub の Issue (マイルストーン 5.0.0) が正です。

## 5.0.0 (準備中)

次の大型アップデート。3D のキャラと、キャラと話せるモーニングコールが中心です。

### development に入ったもの

- **キャラとの会話** — `/chat` (Vertex AI の Gemini) で会話し、声は `/tts` (Gemini TTS) か端末の VOICEVOX (ずんだもん)。
  人格・最初のひとこと・終わり方のプロンプトはキャラごとにサーバで持ち、管理画面で編集する
- **3D のキャラ** — VRM を WKWebView (three-vrm) で表示。会話の内容に合わせて表情を変え、瞬きする。最初のキャラは結衣 (VRM を同梱)
- **会話の言語** — 8 言語。キャラが話せればユーザーが選んだ言語で話す
- **今日の予定** — 端末のカレンダーを読んで話す (予定の中身はサーバに保存しない)
- **天気** — 設定で選んだ地域の天気を、電話の最初に話す (WeatherKit REST)
- **話題のニュース** — X の話題を 1 日に数回まとめて取り、Gemini で子ども (9+) 向けに選んで日本語・英語で配る。ホームの「話題」と電話の最初で使う
- **アラームごとの電話の設定** — 電話の長さと、最初に話す内容 (予定・天気・ニュース) をアラームごとに決める
- **タップのセリフ** — 日付・時間帯・曜日で変わるセリフ。管理画面で作る
- **課金・広告** — RevenueCat のプレミアム。アラームは無料 1 つ・プレミアム 10 まで、今日の予定と話題はリワード広告で使える
- **管理画面** — キャラの追加・編集、リソースのアップロード、タップのセリフ、お知らせ
- **個人情報を置かない** — 登録時の IP の保存をやめ、ログに認証情報・個人情報を出さず、ロググループの保持期間を 30 日に
