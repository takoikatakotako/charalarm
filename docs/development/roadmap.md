# ロードマップ

Charalarm の開発ロードマップ。現状と、これからやりたいことの一覧。

## 完了

- **ずんだもんとの音声会話** — 端末内 VOICEVOX 合成 ＋ backend `/chat`（LLM, デフォルト OpenAI）で
  ターン制の双方向会話。CallKit 着信フローに接続（着信を取ると会話が始まる）。
  設計は [zundamon-voice-conversation.md](./zundamon-voice-conversation.md)。
- **ずんだもんを正式キャラとして追加** — chara-table 登録・アセット配信を整備し、
  結衣/紅葉と並んで選択可能に（従来はデフォルトだが一覧に出ていなかった）。
- **お知らせ配信** — 管理画面から作成/削除 → アプリ内お知らせ一覧に表示（プッシュ通知なし・即時公開）。
- **管理画面の書き込み経路修正** — Lambda Function URL を auth=NONE ＋ CloudFront 注入の
  秘密ヘッダ検証に変更し、OAC が POST ボディに署名できず 403 になる問題を解消。

## 次の一手 / 中長期

- **会話の作り込み** — ペルソナ/終話の自然さ、聞き直し精度、長さ調整。実機での通し確認。
- **四国めたんの追加** — VOICEVOX styleId で会話キャラ化。立ち絵・ボイス等のアセット準備が前提。
- **管理画面でのセリフ / 会話プロンプト管理** — ずんだもん（合成）はテキストで管理しやすい。
  録音ボイスのキャラは音声アップロードのパイプラインが必要。書き込み経路は整備済み。
- **結衣のクラウド音声で会話対応（プレミアム）** — VOICEVOX 自作はハードルが高いため、
  クラウド音声クローン（ElevenLabs 等）を会話ループに追加する。声優の許諾が前提。
  従量コストのため**プレミアム限定**にして課金と接続する（→「課金機能実装」と合流）。
- **キャラ戦略** — 結衣/紅葉は残しつつずんだもんを主役に。詳細は開発メモを参照。
