# プライバシーポリシー

キャラーム運営（以下「当運営」）は、スマートフォン用アプリ「キャラーム」（以下「本アプリ」）で取り扱う情報について、以下のとおり定めます。

当運営は、利用者の個人情報をできるだけサーバに持たない方針で本アプリを作っています。会話の内容や履歴はサーバに保存せず、利用者の端末の中にだけ置きます。


## 1. 当運営のサーバに保存する情報

| 情報 | 使い道 | 保存する期間 |
|---|---|---|
| ユーザー ID と認証用のトークン（端末で作るランダムな文字列） | 利用者を見分けるため | 退会するまで |
| プッシュ通知のトークン | アラームの時刻に電話の着信を届けるため | 退会するまで |
| アラームの設定（時刻・曜日・名前・キャラクター） | 電話をかけるため、アラームの一覧を表示するため | 退会するまで |
| 購入の状態（プレミアムプランかどうか） | プレミアムプランの特典を提供するため | 退会するまで |
| 1日ごとの利用量（会話の回数・読み上げた文字数） | 使いすぎを防ぐため | 2日 |
| サーバの動作記録（ログ） | 不具合の調査のため | 30日 |

- アラームの名前は自由に入力できます。氏名や連絡先などの個人情報は入力しないでください。
- 当運営は、IP アドレスを保存しません。
- サーバの動作記録には、会話の内容、カレンダーの予定、認証用のトークンを残しません。


## 2. 会話機能で扱う情報

キャラクターとの会話は、次の流れで行います。

1. 利用者の声は、端末の音声認識（Apple の機能）で文字にします。音声認識の処理のため、音声が Apple に送られることがあります。
2. 文字にした発言と、会話の流れ（直前のやりとり、端末に保存しているキャラクターの記憶）を、当運営のサーバを通して Google（Gemini）に送り、キャラクターの返事を作ります。
3. キャラクターの返事を、当運営のサーバを通して Google（Gemini）に送り、音声にします。

- 当運営のサーバは、会話の内容を保存しません。
- 会話の履歴とキャラクターの記憶は、利用者の端末の中にだけ保存します。アプリを削除すると消えます。
- 会話機能は18歳以上の方を対象としています（利用規約 第5条の2）。


## 3. カレンダーの予定

カレンダーへのアクセスを許可した場合に限り、キャラクターが今日の予定について話すため、次の情報を扱います。

- 本アプリの設定で選んだカレンダーにある、今日の予定のタイトルと時刻
- 予定の場所、メモ、参加者は読みません。

予定は会話のときだけ当運営のサーバを通して Google（Gemini）に送り、当運営のサーバには保存しません。使うカレンダーは本アプリの設定で選べ、端末の「設定」アプリからいつでもアクセスを取り消せます。


## 4. 外部のサービス

本アプリは、次のサービスを利用しています。各サービスでの情報の扱いは、それぞれのプライバシーポリシーをご覧ください。

| サービス | 提供元 | 使い道 | 送る主な情報 |
|---|---|---|---|
| Gemini（Vertex AI） | Google | 会話の返事と音声を作る | 発言、会話の流れ、今日の予定（許可した場合） |
| 音声認識・プッシュ通知 | Apple | 声を文字にする、電話の着信を届ける | 音声、プッシュ通知のトークン |
| Firebase（Analytics・Crashlytics・Authentication） | Google | 利用状況の分析、クラッシュの調査、匿名の認証 | 端末の種類、OS のバージョン、アプリの操作、クラッシュの記録 |
| AdMob | Google | 広告の表示 | 広告識別子（トラッキングを許可した場合）、端末の情報 |
| RevenueCat | RevenueCat, Inc. | プレミアムプランの購入と状態の管理 | ユーザー ID、購入の記録 |
| Amazon Web Services | Amazon | 当運営のサーバ | 「1. 当運営のサーバに保存する情報」の情報 |

- これらのサービスの一部は日本国外にあり、情報が国外で処理されることがあります。
- プレミアムプランに登録すると、広告は表示されません。


## 5. 第三者への提供

当運営は、次の場合を除き、利用者の情報を第三者に提供しません。

- 「4. 外部のサービス」に書いた目的で、各サービスに送る場合
- 法令に基づく場合


## 6. 退会と情報の削除

本アプリの設定の「リセット」で退会すると、当運営のサーバにある利用者の情報（ユーザー ID、プッシュ通知のトークン、アラームの設定、購入の状態）を削除します。1日ごとの利用量とサーバの動作記録は、上の期間が過ぎると自動で消えます。

端末に保存している会話の履歴とキャラクターの記憶は、本アプリを削除すると消えます。

## 8. このポリシーの変更

当運営は、必要に応じてこのポリシーを変更することがあります。変更後のポリシーは、このページに掲載した時点から効力を持ちます。
